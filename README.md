A program that draws Wednesday 18 November 2026's world news as one broadsheet poster image — Trump flying from Manila to Shenzhen for the APEC summit and talks with Xi, Cyclone Akvan turning severe off India's coast, a record day of migrant arrivals in the Canary Islands, Prince Harry meeting wounded veterans in Lviv, India condemning the Hormuz tanker attack, and more — and writes it to `/output/entry.png`. Pure Python 3.13 standard library, fully deterministic: two runs write byte-identical PNGs.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
